M2Hub è un programma per il tuo computer. Raccoglie ciò che altrimenti si
sparpaglia tra schede del forum, foglietti e tabelle Excel: quali eventi sono in
corso, cosa arriva nell'item shop, come stanno i tuoi account e personaggi, cosa
hanno reso le run della serata – e quanto costa un livello di gilda.

> L'interfaccia è disponibile in **tedesco, inglese, turco e italiano**. I dati
> arrivano sempre dal forum tedesco ufficiale; la traduzione avviene al momento
> di mostrarli.

## Primi passi

1. Dalla [pagina di download](https://github.com/EinfachFabsTV/Metin2Hub/releases/latest)
   scarica il file `M2Hub.exe`.
2. Doppio clic – fatto. Non c'è installazione né configurazione.
3. Al primo avvio Windows mostra un avviso blu. È normale ed è spiegato passo
   passo qui sotto: [L'avviso blu di Windows al primo
   avvio](#lavviso-blu-di-windows-al-primo-avvio).

Serve Windows 10 o più recente. Nient'altro va installato – il programma porta
con sé tutto ciò che gli occorre.

## L'avviso blu di Windows al primo avvio

Alla prima apertura compare una finestra blu:

> **Windows ha protetto il PC**
> Microsoft Defender SmartScreen ha impedito l'avvio di un'app non riconosciuta.

All'inizio c'è solo il pulsante **«Non eseguire»**. La strada passa dal
collegamento:

| Passo | Cosa fare |
|:--:|---|
| 1 | Clicca su **«Ulteriori informazioni»** – il link sotto il testo |
| 2 | La finestra si apre e mostra `App: M2Hub.exe` e `Editore: Editore sconosciuto` |
| 3 | Clicca su **«Esegui comunque»** |

È tutto – l'avviso compare solo la prima volta. Poi M2Hub parte con un doppio
clic.

> [!TIP]
> **Se «Ulteriori informazioni» non c'è** o il download è stato bloccato prima:
> tasto destro su `M2Hub.exe` → **Proprietà** → in basso, alla voce
> «Sicurezza», spunta **«Annulla blocco»** → **OK**.

### Perché compare questo avviso?

Non dice nulla sul contenuto del file. Windows semplicemente non conosce ancora
il programma: SmartScreen avvisa per ogni applicazione che non ha una firma
acquistata né è già stata scaricata da molte persone. Una firma del genere
costa diverse centinaia di euro l'anno – per un progetto gratuito della
comunità non è ragionevole.

Non è quindi un **avviso antivirus**, ma una nota su un editore sconosciuto. Con
l'aumentare dei download sparisce da sé.

### Restare al sicuro

- **Scarica M2Hub solo dalla
  [pagina di download ufficiale](https://github.com/EinfachFabsTV/Metin2Hub/releases/latest).**
  File presi da forum, hoster o allegati Discord possono essere stati
  modificati – lì l'avviso è giustificato.
- Il file si chiama sempre `M2Hub.exe` ed è grande circa 92 MB. File
  sensibilmente più piccoli o varianti con aggiunte nel nome non vengono da qui.
- Per esserne certi, confronta la somma di controllo: accanto al file, nella
  pagina della release, c'è un valore `sha256:…`. In PowerShell
  `Get-FileHash .\M2Hub.exe` restituisce lo stesso valore se il file è
  invariato.

Se il tuo antivirus segnala qualcosa, anche questo dipende dall'editore
sconosciuto – è un falso positivo. Se hai dubbi, carica il file su
[VirusTotal](https://www.virustotal.com) e guarda il risultato prima di
avviarlo.

## 🔒 &nbsp;I tuoi dati restano sul tuo computer

Non è una promessa ma una scelta costruttiva: **M2Hub non ha un server.** Non
esiste un posto verso cui i dati potrebbero fluire.

|  | |
|:--:|---|
| 🚫 | **Nessun account, nessun accesso, nessuna password.** Non c'è niente da creare e niente da perdere. |
| 💾 | **Account, personaggi, medaglie e le run inserite restano solo da te**, in file nella tua cartella utente di Windows. Non vengono trasmessi da nessuna parte – nemmeno a noi. |
| 👁️ | **Nessuna raccolta di dati d'uso**, nessuna pubblicità, nessun pixel di tracciamento. |
| 🔑 | **Non ti vengono mai chiesti dati d'accesso.** M2Hub non ha bisogno della tua password di gioco e non la salverebbe. Se un programma che si spaccia per M2Hub te la chiede, non è M2Hub. |

Il programma tocca la rete in un punto solo: legge il calendario eventi pubblico
e gli annunci nel forum ufficiale di Metin2 – le stesse pagine che apriresti nel
browser. Quelle informazioni restano sul tuo computer; ciò che è in corso o deve
ancora arrivare rimane, le voci scadute vengono scartate dopo sette giorni.
Nessun dato personale viene trasmesso.

Per salvare le tue voci o portarle su un altro computer, copia i file
`accounts.json`, `runs.json` e `goals.json` – li trovi con **Impostazioni →
Apri cartella**. Le run inserite non vengono mai scartate; sono misurazioni
tue, non dati scaricati.

## Aggiornamenti

All'avvio M2Hub controlla se c'è una versione più recente. Alla pressione di un
pulsante la scarica, si sostituisce e riparte – non serve scaricare a mano.

Se preferisci di no, disattiva il controllo nelle impostazioni.

## Codice sorgente

Il codice sorgente completo dell'app si trova in questo repository sotto
[`desktop/`](desktop). A ogni pubblicazione viene aggiornato dallo stesso banco
di lavoro che compila `M2Hub.exe` – programma e sorgente appartengono sempre
allo stesso stato.

Chi vuole sapere cosa fa il programma non deve credere a nessuno:

- **Nessun account, nessun server.** Non c'è accesso né un servizio che riceva
  dati. Si legge in
  [`Services/LocalStore.cs`](desktop/M2Hub.Desktop/Services/LocalStore.cs):
  tutto sta come JSON nel tuo profilo.
- **Una sola destinazione in rete** – il forum tedesco ufficiale. I tre
  indirizzi sono scritti per intero in
  [`Services/Forum/ForumSource.cs`](desktop/M2Hub.Desktop/Services/Forum/ForumSource.cs);
  l'unica altra connessione va a GitHub, per cercare una versione più recente.
- **Nessun WebView, nessun Chromium.** Il disegno passa da Avalonia/Skia; non
  c'è un motore di browser in cui potrebbe girare codice estraneo.

### Compilarlo da sé

Con il [.NET SDK 9](https://dotnet.microsoft.com/download) e nient'altro:

```bash
cd desktop/M2Hub.Desktop
dotnet publish -c Release -r win-x64 --self-contained true \
  -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true
```

### Verificare il file scaricato

Per ogni pubblicazione la somma SHA256 di `M2Hub.exe` è nelle note di rilascio.
Per ricalcolarla su Windows:

```powershell
Get-FileHash .\M2Hub.exe -Algorithm SHA256
```

Se il valore coincide, il file è esattamente quello compilato dal codice
visibile qui.

### Perché SmartScreen protesta

Il file non è firmato con un certificato – certificati del genere costano e non
dicono nulla sul contenuto. Windows quindi non conosce il file e avvisa. Codice
sorgente e somma di controllo dicono più di una firma.
