# Metin2Hub
M2Hub ist dein zentrales Dashboard für Metin2: Event-Tracker: Ingame- &amp; ItemShop-Events direkt im Blick. Charakter-Verwaltung: Führe lokale Listen für Gildenspenden, Medaillen, Biologen-Fortschritt &amp; Meley-Run-Rollen. Perfekte Übersicht für dein tägliches Gameplay – ohne externe Tabellen!
